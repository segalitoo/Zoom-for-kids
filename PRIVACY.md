# Zoomi — Privacy Policy

**Last updated:** March 11, 2026

## Overview

Zoomi is a Chrome extension that adds a kid-friendly control panel to Zoom web meetings. It provides large, colorful buttons for reactions, hand raise, and mute — designed for children ages 5–12.

## Data Collection

Zoomi does **not** collect, store, or transmit any user data. Specifically:

- **No personal information** is collected
- **No analytics or tracking** is used
- **No cookies** are set
- **No data is sent** to any server
- **No user accounts** are required

## How It Works

Zoomi runs entirely in your browser. It reads Zoom's meeting interface (button labels and states) on `zoom.us` pages to detect meeting controls, and simulates clicks on those controls when the user presses Zoomi's buttons. All processing happens locally in the browser.

## Permissions

- **activeTab**: Used to detect if the current tab is a Zoom meeting
- **Host permission (zoom.us)**: Required to inject the kid-friendly control panel into the Zoom web interface

## Third-Party Services

Zoomi loads the "Varela Round" font from Google Fonts. Google's privacy policy applies to that request: https://policies.google.com/privacy

## Children's Privacy

Zoomi is designed for use by children. We do not knowingly collect any information from children or any other users.
